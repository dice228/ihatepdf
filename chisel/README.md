# Chisel

Мини-приложение для macOS: конвертирует MOV и другие распространённые форматы
в MP4 с кодеком H.264, показывая размер файла до и после — с пересчётом в реальном времени.

## Что внутри

Интерфейс сведён к минимуму. Пустое окно: только светофор, заголовок «Chisel»
и строка «Выберите видео или перетащите его сюда». Файл можно выбрать кликом,
перетащить в окно или вставить из буфера обмена (⌘V).

После выбора видно превью, имя файла, размер «сейчас», размер «после»,
два ползунка — разрешение и битрейт видео — и выбор битрейта звука.
Ниже — «Конвертировать» и «Отмена».
Если файлов несколько, слева появляется список; когда файл один, списка нет.

Над ползунками стоит чекбокс «Параметры на все видео», включённый по умолчанию.
Пока он включён, настройки общие для всей очереди, а список слева только показывает
состояние файлов — выбирать отдельное видео незачем, и строки не кликаются.
Цифры «сейчас» и «после» в этом режиме показывают сумму по всем файлам.
Выключите чекбокс — список станет активным, и каждое видео получит свои настройки.

## Сборка

Нужны только инструменты разработчика (`xcode-select --install`), полный Xcode не требуется.

```
cd chisel
./build.sh              # под текущий процессор
./build.sh --universal  # Apple Silicon + Intel
./build.sh --install    # сразу положить в /Applications
```

Готовое приложение окажется в `chisel/build/Chisel.app`.

## Иконка

В репозитории лежит `Resources/Chisel.icns`, нарисованный по мотивам вашего логотипа
скриптом `tools/make_icon.py`. Чтобы подставить оригинальный файл:

```
./tools/use-my-logo.sh ~/Documents/logo.png
./build.sh
```

## Как считается «размер после»

Размер файла у H.264 определяется битрейтом, а не разрешением:

```
размер ≈ (битрейт видео + битрейт звука) × длительность ÷ 8
```

Поэтому оба ползунка связаны через плотность бит на пиксель. Ползунок битрейта
задаёт именно эту плотность, а при изменении разрешения битрейт пересчитывается
пропорционально числу пикселей — качество картинки остаётся тем же, а размер меняется.
Так обе настройки влияют на цифру «после», и она обновляется мгновенно, без пробного кодирования.

Дробь разрешения общая, а битрейт у каждого файла получается свой: при общих параметрах
на всю очередь раздаётся именно плотность бит на пиксель, поэтому файл 4K и файл 720p
не получат один и тот же битрейт.

Битрейт по умолчанию берётся из самого файла, но не выше разумного потолка:
для ProRes или другого тяжёлого исходника это сразу даёт заметное сжатие.
Поднимать битрейт выше исходного бессмысленно — приложение об этом предупреждает.

## Звук

Битрейт звука на видео не распространяется — это отдельная дорожка, и у неё свой вес:
AAC 128 кбит/с занимает около 1 МБ на минуту. На длинном ролике с низким битрейтом видео
это заметная доля файла, поэтому звук вынесен в отдельный ряд кнопок: 64, 96, 128, 192, 256
или «выкл». Под ним написано, сколько мегабайт добавит дорожка при текущем выборе.

Для речи 64 кбит/с звучит разборчиво, для музыки заметна разница ниже 128.
Совсем выбросить звук имеет смысл для экранных записей и таймлапсов —
там это чистый выигрыш веса. Дорожка всегда пережимается в AAC,
многоканальный звук сводится в стерео.

## Движок

Основной путь — AVFoundation (`AVAssetReader` → `AVAssetWriter`) с аппаратным
кодированием через VideoToolbox. Ничего доустанавливать не нужно: MOV, MP4, M4V,
HEVC, ProRes и прочее, что открывает сама macOS, обрабатывается «из коробки».
Поворот из метаданных применяется к картинке, звук перекодируется в AAC 128 кбит/с,
а `shouldOptimizeForNetworkUse` переносит индекс moov в начало файла,
чтобы видео начинало играть без полной загрузки.

Контейнеры, которые macOS не открывает (MKV, WebM), подхватываются через ffmpeg,
если он уже установлен (`brew install ffmpeg`). Без ffmpeg такие файлы
просто сообщат, что формат не поддерживается.

## Ограничения

Файлы с переменной частотой кадров (запись с iPhone) приводятся к постоянной частоте —
это делает оценку размера точной и не мешает воспроизведению.
Приложение не подписано сертификатом разработчика: собранное у себя — запускается без вопросов,
но если переносить `.app` на другой Mac по сети, Gatekeeper попросит подтверждение.
